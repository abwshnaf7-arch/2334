# كارت التصوير للمالك: ريل "مونتير يدوي ضد Happy Duck AI"

## الإعدادات (مرة واحدة)
- **برنامج التسجيل:** OBS Studio (مجاني). Settings > Video: Base و Output = دقة شاشتك الأصلية، FPS = 60. Settings > Output (Advanced): Encoder = NVENC لو عندك كارت NVIDIA وإلا x264، Rate Control = CQP، CQ Level = 16، Recording Format = mkv (بعدين File > Remux Recordings).
- **المصدر:** Display Capture لشاشة بريمير، المؤشر ظاهر. بدون صوت.
- **الشاشة:** Scaling 100% في ويندوز، بريمير Maximized، قفّل الإشعارات (Focus assist)، اقفل أي تابات شخصية.
- **المؤقت:** افتح تطبيق Clock في ويندوز > Stopwatch، كبّره وخليه Always on top في ركن الشاشة (لازم يبان في كل فريم).
- **اللوحة:** كبّر لوحة Happy Duck AI في بريمير بحيث الكلام جواها يبان كبير.
- كل التسجيلات بالترتيب ده، **تيك واحد نضيف لكل مرة** (لو غلطت، اعمل تيك جديد وقول لجيميناي).

## اللقطات المطلوبة (بالترتيب)
| # | اسم الملف | اللي تعمله |
|---|---|---|
| S0 | `raw_clip.mp4` | كليب خام عمودي بتليفونك (1080x1920، إضاءة كويسة، صوت نضيف). **اقرا النص تحت** (60 ثانية). متقصش ومتعدلش فيه حاجة. |
| S1 | `take_B_extension.mkv` | مشروع جديد > Sequence عمودي 1080x1920 > حط الكليب. ابدأ المؤقت + التسجيل. اختار الكليب > **Smart Cut** > **Repetition Removal** > **Cut & Clean** > نافذة المراجعة تظهر: **رجّع جملة واحدة بالضغط على ↩** > **Delete N segments** > تبويب **Caption** > ستايل **Word Box** > **Generate Caption**. وقف المؤقت لما السكتات والتكرار تتشال وكل كلمة يبقى عليها كابشن. |
| S2 | `take_A_manual.mkv` | مشروع جديد، نفس الكليب. ابدأ المؤقت + التسجيل. اقص بإيدك (Razor + Ripple Delete) السكتات والتكرار، وبعدين الكابشن بأدوات بريمير الأصلية (Window > Text > Captions > Transcribe). لو العربي مش مدعوم أو بيتبوّظ، سيبه يبان في التسجيل واكتب الكابشن بإيدك. وقف المؤقت بنفس الشرط. |
| S3 | `native_arabic_captions.mkv` | 30-60 ثانية: بريمير الأصلي، Transcribe sequence للكليب بالعربي، ونتيجته في Program monitor (قرّب على الكلام). |
| S4 | `panel_closeups.mkv` | لوحة الإضافة بس، حركة ماوس بطيئة: تحليل الصوت، نافذة المراجعة، ستايلات الكابشن، شريط التقدم، محرر الكابشن (20 ثانية لكل حالة). |
| S5 | لقطات ثابتة PNG | Print Screen (بدقة الشاشة): بريمير قبل التعديل، بعد اليدوي، بعد الإضافة. |
